# Portfolio Website

My personal portfolio showcasing my work as a Backend Developer.

## 🌐 Live Demo

🔗 https://anit-portfolio-gamma.vercel.app/

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Dark theme with purple gradient accents
- JetBrains Mono font for a developer-inspired aesthetic

## Features

- ✨ Terminal typing animation
- 💻 Interactive code snippets
- 📄 Resume download
- 📱 Fully responsive design
- 🎮 Hidden Easter egg (try the Konami code!)


## Run Locally

Clone the repository:

```bash
git clone https://github.com/AnitSelvaPreetha/Professional_Portfolio.git
```

Open `index.html` in your browser.

## Deployment

Deployed on **Vercel**.
